# Placeholder Icons

For production, replace these with proper PNG icons:

- icon16.png (16x16)
- icon48.png (48x48)  
- icon128.png (128x128)

You can use the icon.svg as a template and convert to PNG using:
- Online tool: https://cloudconvert.com/svg-to-png
- CLI: `convert icon.svg -resize 128x128 icon128.png`

Or use any design tool (Figma, Photoshop, etc.)
