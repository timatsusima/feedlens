# FeedLens Roadmap

## ✅ MVP (Current)

- [x] Chrome Extension (Manifest v3)
- [x] Video collection from YouTube homepage
- [x] Anonymous snapshot publishing
- [x] Public snapshot pages
- [x] PostgreSQL storage
- [x] Basic metadata (nickname, city, age, description)

### Search & Discovery
- [ ] Search snapshots by nickname
